# auth-app-practice

## 概要
COACHTECH 教材 Tutorial 10-1「認証機能 ハンズオン演習」で作成した成果物です。
（ログイン・ログアウト・ユーザー登録機能と、認証が必要なダッシュボードを作成しました。）

## 使用技術
- PHP 8.x
- Laravel 10.x
- Laravel Fortify（認証）
- MySQL

## 学んだこと
- fortifyでの登録・ログイン・ログアウト設定
- config/fortify.phpでhome,redirect設定が必要なこと

## 動作確認
http://localhost/register にアクセス
